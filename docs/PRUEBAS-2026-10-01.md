# Validación TRAZVA — 1 de octubre de 2026

## Verificado

- 18 productos: 8 del archivo y 10 de running.
- Búsqueda por nombre/marca, filtro por uso, marca y 3D; orden y estado sin resultados.
- Comparación de 2–3 modelos, límite de tres y enlace compartible.
- Rotación guardada en D1 local real; recarga, duplicación, exportación y eliminación.
- Formulario: persistencia de consulta con referencia, recuperación, eliminación y escape de HTML.
- API: identidad obligatoria, origen validado, datos inválidos rechazados, registros separados por usuario, reintentos idempotentes.
- Pruebas automatizadas de API incluidas en `tests/api.test.mjs`; ejecutar `npm run build && npm test`.
- Bolsa anterior, talla, enlace de producto y visor local Pegasus 36.
- Portada con GLB local. Los ocho archivos originales y sus licencias se conservan.
- Ocho páginas revisadas en 1440, 768, 390 y 320 px; imágenes cargadas y sin desbordamiento horizontal después de corregir tarjetas/filtros estrechos.
- Sintaxis JavaScript, imports y rutas locales: `npm run check`.
- Sin errores JavaScript propios de la aplicación durante los flujos de navegador.

## Visores de terceros

Cuatro modelos concretos se integran mediante la API pública de Sketchfab. Se validaron los IDs, metadatos y páginas del proveedor, la carga solo bajo demanda y la eliminación al cerrar. El entorno de navegador no completó consistentemente la carga del servicio externo; no se da su renderizado por verificado. El sitio conserva la fotografía, muestra el estado de carga, ofrece reintento y enlace al original. Estos visores necesitan conexión y pueden depender de disponibilidad del proveedor.

Los seis modelos restantes de running tienen fotos de fabricante, no un GLB aproximado. EVO SL y 1080v15 incluyen además un enlace al escaneo de RTINGS (acceso sujeto a sus condiciones).

## Límites operativos

Las pruebas de escritura se ejecutaron con identidades ficticias y D1 local; no se sembraron datos de prueba en producción. El render externo, el acceso desde una sesión real de propietario y las conexiones comerciales no se confunden con esas pruebas. No hay pago, envío de correo, inventario comercial o cuentas sociales activas.
